Used checklist

中古は、値札より白画面を見る。

  1. 01白画面でドット・色ムラ・内部埃を確認
  2. 02ランプ使用時間と交換履歴を確認
  3. 03HDMI入力・4K表示・リモコンを確認
  4. 04ファン異音や高温時の停止がないか確認
  5. 05Android TVドングル等の付属品を確認
