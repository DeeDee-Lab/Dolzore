# DOLZORE

Canonical GitHub source for the DOLZORE public website.

## Current direct-user scope — 2026-09-28

DOLZORE is currently a **music-only storefront plus Journal**.

- Sale scope: Creator BGM only
- Catalog: 60 tracks
- Price: ¥200 / track / buy once
- Public preview: bounded sample clips only
- Full purchased audio must never be published in this repository's public site
- Non-music products/services are stopped and hidden until explicitly re-authorized
- Journal articles are produced through a GitHub handoff with the article Agent

## Experience direction

The public site is an original DOLZORE world:
- playful 16-bit-JRPG-like exploration
- pastel + vivid accents
- pixel language and game-like interaction
- black dialogue/menu windows
- original retro jukebox for music discovery

MOTHER2/EarthBound and nob-sakuma.com are high-level experience references only. Do not copy protected characters, sprites, maps, logos, music, dialogue, exact UI, page layouts, artwork or text. Do not imitate a living writer's exact prose.
