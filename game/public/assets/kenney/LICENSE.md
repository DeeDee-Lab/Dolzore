The imported files were copied from the public repository

DOLZORE usage policy:
- these assets provide a production-quality base and reference layer;
- signature characters, important landmarks, major enemies, BAR identity,
  story-critical visuals and brand art will become original DOLZORE assets;
- third-party assets never define DOLZORE lore or story canon.
