# ANIMAL CROSSING — ECONOMY / COLLECTION / PROGRESSION

Authority: DeeDee-Lab/Dolzore#40

## 1. Core progression pattern

The series avoids combat-power progression as its center.
Progress is distributed across:
- home expansion;
- catalog;
- museum;
- relationships;
- town/island infrastructure;
- collection;
- money;
- design library;
- event participation;
- crafting/resource unlocks;
- social sharing.

## 2. Soft economy

Classic flow:
collect / fish / catch / sell / help
-> general currency
-> debt / furniture / clothing / services
-> stronger personal expression
-> more reasons to return.

New Horizons adds:
resource gathering
-> recipes
-> crafting
-> tools/furniture/infrastructure.

Pocket Camp compresses this into:
requests
-> friendship/material rewards
-> crafting
-> campsite growth
-> event loop.

## 3. Market separation

Recommended DOLZORE economy domains:
- general currency;
- materials;
- collection objects;
- civic/project resource;
- seasonal/event currency;
- social/reputation progression.

Avoid too many currencies.

## 4. Weekly speculative market

NHSE public structures include TurnipStonk / GSaveShopKabu, proving New Horizons persists dedicated weekly turnip-market state.

Design principle:
A weekly market creates:
- recurring appointment;
- community discussion;
- risk/reward;
- reasons to visit others.

DOLZORE may create an original weekly commodity market, not the same turnip fiction or formulas.

## 5. Collection model

CollectionEntry:
- content_id;
- discovered;
- owned;
- donated/registered;
- first_date;
- first_location;
- best/size/quality optional;
- seasonality;
- journal text key;
- provenance.

Museum-like display should be separate from raw possession.

## 6. Spawn vs value

Rare object value works because acquisition conditions differ:
- time;
- month;
- weather;
- habitat;
- rarity;
- skill/action.

Do not make rarity only a low RNG percentage.

## 7. Shop inventory

Shop stock should be a deterministic/seeded rotation with:
- catalog pool;
- unlock tier;
- season;
- event;
- player progression;
- duplicate suppression;
- rare slots.

Persist generated stock for the period so reloads do not reroll freely.

## 8. Debt / long horizon

Debt is effective when:
- non-punitive;
- player-controlled pace;
- repayment unlocks visible space/status;
- no failure timer.

DOLZORE can use civic/home project financing without coercive penalties.

## 9. Content abundance

Happy Home Designer official guide metadata reports:
- more than 5,250 item entries;
- 387 clients.

Pocket Camp Complete official material states 10,000+ items.

These figures demonstrate a core production lesson:
life-sim identity emerges from combinatorial content volume.

Therefore DOLZORE needs:
- schema-driven items;
- batch authoring;
- localization pipeline;
- automated validation;
- tagging/search;
- variant generation;
- catalog browser.

## 10. Anti-copy

Do not import:
- Bells/Nook Miles fiction;
- turnips;
- Nintendo item lists;
- prices;
- recipes;
- museum text;
- exact reward loops.

Copy only the architectural principle:
many orthogonal soft goals with persistent visible completion.
