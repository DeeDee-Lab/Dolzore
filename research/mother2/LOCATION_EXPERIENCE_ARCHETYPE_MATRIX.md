# MOTHER2 LOCATION / EXPERIENCE ARCHETYPE MATRIX

Authority: DOLZORE MOTHER2 research issue #26
Purpose: classify the kinds of places/experiences MOTHER2 combines, without reproducing map layouts.

## 0. Important interpretation

This is a functional taxonomy, not a reconstruction of the MOTHER2 world map.
Place names below may be used only as reference labels for analysis.
DOLZORE must invent its own names, geography, architecture and event sequences.

## 1. Archetype A — hometown / domestic launch point

Reference examples: early Onett/home context.

Functions:
- establish ordinary life;
- teach movement/interaction;
- create family/social baseline;
- introduce first abnormal threat;
- provide a future emotional comparison point.

DOLZORE use:
First town should contain at least one domestic/ordinary anchor that remains revisitable.

## 2. Archetype B — small neighboring town with social objective

Reference example: Twoson-type progression.

Functions:
- widen society beyond home;
- introduce stronger social institutions/venues;
- make travel feel geographic rather than menu-based;
- combine rescue/problem-solving with local leisure.

DOLZORE use:
Second major district/town should change social character, not only enemy level.

## 3. Archetype C — town under visible crisis

Reference example: Threed-type horror/crisis space.

Functions:
- familiar town grammar distorted by danger;
- reduced safety;
- residents react to crisis;
- nightlife/darkness/ambience can shift;
- field enemy pressure invades civic space.

DOLZORE use:
Reuse an established urban grammar under altered state to prove the world can transform.

## 4. Archetype D — major metropolis / vertical or institutional density

Reference example: Fourside-type large-city role.

Functions:
- scale jump;
- commerce;
- institutions;
- high NPC density;
- social complexity;
- hidden underside/anomaly.

DOLZORE use:
Large city identity should come from function + social density + verticality/route complexity, not just larger map dimensions.

## 5. Archetype E — leisure/resort recovery town

Reference example: Summers-type role.

Creator evidence:
Miura explicitly describes a pleasurable, relaxed destination before harsher travel.

Functions:
- recovery;
- visual/audio relief;
- food/leisure culture;
- temporary reduction in threat;
- tonal reset.

DOLZORE use:
Build one location where "doing nothing important" is part of the intended experience.

## 6. Archetype F — remote school/research/cold-region start

Reference example: Winters/Jeff route.

Functions:
- temporary character perspective change;
- new climate;
- institutional setting;
- separation from main party;
- travel montage/long-route feeling;
- recontextualize world scale.

DOLZORE use:
A temporary off-main-route playable perspective can deepen world scale if it introduces distinct mechanics/relationships, not only exposition.

## 7. Archetype G — desert / exposure corridor

Reference example: Dusty Dunes / Scaraba travel roles.

Functions:
- sparse visual field;
- environmental exposure;
- long-distance travel sensation;
- different encounter rhythm;
- oasis/settlement becomes more valuable.

DOLZORE use:
Low object density can be meaningful if navigation, hazards, audio and destination anticipation compensate.

## 8. Archetype H — wetland/swamp high-friction region

Reference example: Deep Darkness-type role.

Functions:
- movement friction;
- reduced visibility/comfort;
- resource attrition;
- sound-heavy atmosphere;
- relief after exit.

DOLZORE use:
Environmental movement modifier must be readable and have counterplay; avoid pure slow walking as content.

## 9. Archetype I — hidden/isolated community

Reference example: Saturn Valley-type function.

Functions:
- distinct language/culture;
- strong visual/audio identity;
- social relief;
- unusual services;
- memorable residents.

DOLZORE use:
A hidden community needs a complete local norm, not merely "weird NPCs."

## 10. Archetype J — alternate familiar reality

Reference example: Moonside-type function.

Functions:
- familiar city logic transformed;
- navigation rules destabilized;
- palette/visual language radically shifts;
- NPC semantics become unreliable;
- player re-examines known space.

DOLZORE use:
ZURE layers can transform familiar districts with new semantic rules instead of building every anomaly as a new map.

## 11. Archetype K — internal/psychological space

Reference example: Magicant-type function.

Functions:
- free art direction from mundane realism;
- autobiographical/emotional content;
- inward progression;
- symbolic encounters;
- intimate pacing.

DOLZORE use:
Time/memory spaces should be authored around character psychology, not generic dream visuals.

## 12. Archetype L — oversized/scale-disrupting world

Reference example: Lost Underworld-type function.

Functions:
- alter scale expectation;
- visual spectacle;
- traversal reorientation;
- late-game world expansion.

DOLZORE use:
Change perceived scale using camera, prop scale, creature size, terrain rhythm and sound, not only bigger player sprite.

## 13. Archetype M — civic anomaly / cult or collective behavior

Reference example: Happy Happy Village-type role.

Functions:
- community-wide behavior change;
- visual motif saturation;
- social pressure;
- dialogue reinforces local ideology;
- ordinary village function becomes unsettling.

DOLZORE use:
Collective anomaly should modify multiple systems:
- NPC routines;
- color/signage;
- music;
- services;
- dialogue;
- encounter profile.

## 14. Archetype N — route dungeon embedded in ordinary travel

Examples include caves/tunnels/valleys between destinations.

Functions:
- compress encounter pressure;
- gate travel;
- create directionality;
- establish destination as earned.

DOLZORE use:
Do not make every dungeon an isolated "level." Some should simply be dangerous geography between lived-in places.

## 15. Archetype O — sanctuary / memory landmark

Reference macro-system: eight melody/sanctuary journey.

Functions:
- recurring objective type;
- environmental identity;
- personal/introspective payoff;
- repeated structural rhythm with varied local execution.

DOLZORE use:
A repeated pilgrimage structure can organize a long RPG if each site has different traversal/emotional meaning.

Do not reuse melodies, sanctuary names, exact number, or story function.

## 16. Archetype P — final rupture from ordinary world

Late-game reference pattern:
The world journey eventually moves into spaces where ordinary modern-life framing is reduced and threat becomes more abstract/cosmic.

DOLZORE use:
Late-game abstraction gains strength only if most of the game first builds ordinary attachment.

## 17. Transition matrix

Use transitions to communicate scale:

domestic -> neighborhood:
small threshold, no spectacle.

town -> road:
density falls, ambience opens.

road -> crisis town:
visual/social warning before combat spike.

city -> alternate reality:
hard perceptual transformation.

resort -> harsh wilderness:
deliberate comfort-to-stress contrast.

ordinary world -> internal space:
special transition, reduced civic semantics.

late world -> final rupture:
strip familiar affordances progressively.

## 18. Density matrix

Archetype | social | props | encounters | safety | oddity
- hometown: medium / medium / low / high / low-to-medium
- crisis town: low-to-medium / medium / high / low / high
- metropolis: high / high / medium / medium / medium
- resort: medium / high / low / high / low-to-medium
- desert: low / low / medium / low / medium
- hidden community: medium / high-signature / low-to-medium / high / high
- alternate reality: medium / high-transform / variable / low / very high
- internal space: variable / symbolic / variable / variable / very high

These are analytical categories, not measured MOTHER2 statistics.

## 19. DOLZORE implementation rule

The first Unity town should combine only 2–3 archetypes, not all of them.

Recommended first-town composition:
- hometown/civic baseline;
- social pocket;
- subtle local anomaly;
- quiet edge/river;
- station/road exit.

Later towns should deliberately choose different archetype profiles.
